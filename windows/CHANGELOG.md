# Windows 更新记录

## 未发布

- 新增可切换的 DeepSeek 鲸鱼娘桌宠：共享透明图集、八种姿势、三种尺寸、安静模式、动作预览及专属任务／互动文案；保留 Pox 与原生浮球的行为。Windows 启用鲸鱼娘使用 DeepSeek 暗色主题，Pox 使用原角色主题，原生浮球或关闭桌宠跟随系统明暗。
- 两端桌宠文案统一读取 `shared/strings/zh-CN.json`，按角色分流并清理切换前的临时反馈。macOS 新增桌宠与资源加载代码已接入，测试、构建和实机仍待 Mac 验证。
- 调整 Windows 面板圆角、主页图标与导航按钮、输入框和新建账号分段标签；dsh API 余额默认折叠，展开查看分项、缓存／查询状态和连接信息。
- 改进 dsh 安装识别：支持 PATH 包装器、自定义 npm 前缀及官方 npx 缓存，验证包名与 CLI 入口，列出来源和版本供选择；新增手动添加入口、持久错误指引、配置检查、官方启动命令复制和已有实例连接引导。真实 dsh 0.2.1-rc.5 隔离启动与连接恢复通过。
- dsh 历史和空闲会话按最近回合结束事件显示状态：明确完成显示绿色 ✓，停止和错误分别标记；事件查询失败、待处理输入与新任务不会误用旧完成标记。
- 独立查询 dsh 默认 DeepSeek 官方 API 余额，无需 dsh-cost-meter；只读标准文件来源 Key，仅向固定官方 HTTPS 端点鉴权，拒绝重定向且不保存密钥副本。支持多币种总额／充值／赠送、5 分钟自动与即时手动刷新、凭据切换清缓存；已有实例可选择余额凭据目录。
- 修正 dsh 历史／实时会话标题读取，使用官方白色鲸鱼徽标；分开检测官方账户登录与默认模型 API Key 计费通道，30 秒更新状态。
- 新增 DeepSeek Harness（dsh）Web：支持源码构建版、npm 全局／本地安装版及手动连接已有本机实例。
- 独立后台宿主保留任务运行，面板重启恢复连接；授权通过当前用户 DPAPI 加密保存。
- 新增 dsh 根会话状态、官方充值／赠送钱包；断连显示缓存，空闲不误报成功完成。
- 新增 dsh 启动配置、重新连接、显式停止／断开菜单和演示入口；`--theme light|dark|pox|deepseek` 可独立指定演示主题。
- 接力和拆出需求已移除：会话右键菜单不再有“接力到…”和“拆出需求到…”，待接力卡片、设置页的交接文件夹按钮和接力记录，以及交接文档写好的通知也一并去掉。对话完成、等你回应和遇到问题的托盘通知保留。之前留在数据目录 `handoffs/` 下的交接文档和记录不删除，Perch 也不再读取。
- Perch 启动后就开始查询任务状态，不用先打开面板，桌宠立即反映任务。
- 打开面板后点外部能收起，后台刷新额度时也一样。
- 账号和偏好文件内容没变时不再写盘。
- 损坏文件的恢复提示只显示一次，启动时出现的提示不会在面板打开前就消失。
- Codex 任务 30 分钟没有更新就按已停止处理，和 macOS 一致，卡住的任务不再一直显示运行中。
- 调出客户端时只还原最小化的窗口，最大化的窗口保持原样；客户端收在托盘里时也能调出。
- 客户端还在运行时不允许回收它的数据目录。
- 查找客户端和读取本地额度缓存改到后台进行，轮询时界面不卡。
- 额度行放得下“Sonnet 周”这类较长的标签。
- 文件或剪贴板出错时只在面板里提示，不再退出程序。
- Codex 和 Claude 对话从运行中变成已完成、等待输入或遇到问题时，托盘发一条通知，点通知调出所属客户端。同一次轮询有几个对话变化时合成一条，点了打开面板。Perch 启动前已经结束的对话不通知，`codex exec` 启动的委派运行也不通知。设置页“通知”里可以关掉。几条通知同时出现时逐条显示，点哪条就执行哪条。点后台错误的托盘气泡现在会打开面板。

## 0.2.0 — 2026-10-10

- 重做账号、设置、信息和新建页面，支持系统明暗与强调色、Pox 主题、统一菜单和确认框。
- 支持账号、客户端分组和会话拖动排序；刷新保留当前列表对象。
- 新建账号后启动客户端，目录丢失时可重新定位，移除账号可选择回收数据目录。
- 补齐会话文件菜单、单 Codex 实例深链、接力来源与目标记录；剪贴板失败不会生成重复文档。
- 桌宠面板随拖动移动，支持恢复位置、圆角标签、任务反馈与完成气泡。
- 改为进程内状态查询，减少常驻开销；增加多屏定位与损坏偏好恢复。
- 会话文件未变化时不再重复读取，后台空闲 CPU 明显下降。
- 面板打开时显示桌宠，面板会移到桌宠旁边，不再重叠。
- 原生浮球改为纯色圆球；深色模式背景更接近系统弹出面板；托盘右键菜单点外部或按 Esc 可关闭。
- 账号卡片去掉多余空白和孤立分隔线，账号名按可用宽度截断。
- 右键菜单分隔线贯通整行；深色主题使用客户端自带的浅色图标；强调色保留系统色相但降低饱和度。
- 面板打开时切换桌宠或调整大小，面板保持不动，桌宠改到旁边；只有贴近屏幕边缘、放不下时，面板才会让位。

便携版，Windows 10 19041+ x64，解压即用，无需安装 .NET。程序未签名，首次运行若出现 SmartScreen 提示，点“更多信息”→“仍要运行”。
