# Windows 更新记录

## 0.3.0 — 2026-11-14（预览版）

本版新增 DeepSeek Harness（dsh）Web 账号与鲸鱼娘桌宠，并修复跨端审核中发现的路径、连接缓存和启动入口问题。

### 新增能力

- dsh Web 支持源码构建版、npm 全局／本地安装版、官方 npx 缓存，以及手动连接已有本机实例。安装发现显示来源与版本，支持选择命令文件或包目录、配置检查、手动添加指引和持久错误提示；Node、安装目录与 `DSH_HOME` 分开配置。
- 独立后台宿主在 Perch 退出后继续运行任务，重开面板恢复连接并避免重复启动；授权 URL 与 Cookie 使用当前用户 DPAPI 加密。受管服务可显式停止，外部实例只断开连接；移除账号保留服务和数据目录。
- 展示 dsh 根会话标题、工作目录与状态。只有明确的完成事件才显示成功，中断、错误、空闲和未知分别处理；新任务与待处理输入不会沿用旧完成标记，断连保留元数据并标明缓存。
- 分别展示官方登录钱包和 DeepSeek API 余额，保留币种、充值／赠送分项及十进制精度。API 余额仅读指定 home 的标准文件凭据，仅请求固定官方 HTTPS 端点，拒绝重定向，不保存 Key 副本；第三方、环境变量／dotenv 与自定义凭据文件来源不回退查询。
- dsh 账户与计费状态进入 30 秒缓存调度，实际查询随轮询执行；API 余额自动网络请求保留 5 分钟缓存，手动刷新绕过普通缓存，仍遵守 HTTP 429 退避。官方钱包与 API 余额独立显示错误和同一身份的有效缓存。
- 新增可切换的 DeepSeek 鲸鱼娘桌宠：共享透明图集、八种姿势、三种尺寸、安静模式、动作预览及专属任务／互动文案。Windows 启用鲸鱼娘使用 DeepSeek 暗色主题，Pox 保留原主题，原生浮球或关闭桌宠跟随系统。
- 调整账号与新建页面、输入框、圆角、主页导航及余额折叠展示。桌宠文案统一读取共享 JSON；同一仓库的 macOS 实现接入对应 dsh Web 能力并保留原 DSH Desktop／终端入口，两端共用协议样本、文案和角色资源。本下载包仅包含 Windows 应用。

### 修复与调整

- 配置检查与创建账号统一展开 `%USERPROFILE%`、`~`、引号和空格路径，外部实例的余额目录使用相同规则。
- 更换连接或运行描述符时清除上一实例的钱包和会话缓存；受管重连只接受已跟踪服务的原 origin，未知服务须通过“连接已有实例”添加，避免重复启动或停止错实例。
- 桌宠双击可正确打开正在运行任务的 dsh Web 账号；角色切换清除旧角色的临时反馈。鲸鱼娘图集署名与第三方许可随包提供。
- 自动刷新与手动刷新明确区分；自动失败重试遵守节流，既有 HTTP 429 退避保留。后台客户端扫描与额度缓存读取不阻塞面板，账号／偏好内容未变化时不再写盘。
- 保留任务完成、等待输入和错误通知；启动前已结束的任务不补发通知。改进启动即轮询、面板收起、损坏配置提示、窗口恢复与运行中数据目录保护。
- 移除文档接力、拆出需求、待接力卡片及相关菜单；原 `handoffs/` 文件保留，但不再读取。

### 安装与升级

- Windows 10 19041+ x64；便携 ZIP 自带 .NET 运行时，解压后运行 `Perch.exe`，无需另装 .NET。受管 dsh 另需满足所选 dsh 包要求的 Node.js，以及完整的 CLI／Web 构建；连接已有 Web 实例不要求本机另装 Node。
- 程序未签名，首次运行可能出现 SmartScreen 提示。下载 `Perch-Windows-0.3.0-x64.zip` 后可用同一 Release 的 `SHA256SUMS` 核对文件。当前没有安装器、自动升级或开机自启动。
- **升级前先等待受管 dsh 任务结束，在账号菜单显式停止所有由 Perch 启动的 dsh 服务，再退出 Perch，最后替换或解压新版程序。** 仅退出面板不会结束后台宿主，它可能继续占用旧程序文件；显式停止会中断尚未结束的任务。手动连接的外部服务无需因升级而停止。
- 保留 `%LOCALAPPDATA%\Perch`、已有账号数据目录及 `DSH_HOME`。新版继续使用原配置，不迁移或复制 dsh 登录凭据。

### 验证边界

本版包含 Windows Core／WPF、DPAPI、隔离宿主、路径与缓存回归，以及双端共享协议样本；原生 CI 记录见 [PR #7 Checks](https://github.com/0mn1si2i5/perch/pull/7/checks)，详细记录见 [Windows 验收](https://github.com/0mn1si2i5/perch/blob/main/docs/windows/acceptance.md)。发布工作流会再次执行测试和自包含打包。

真实官方登录钱包、真实模型任务／完成通知、桌宠真实鼠标与媒体交互未在本轮全面重验；此前真实安装发现、隔离 Web 启动和 API 余额记录仅代表对应日期的结果。合成样本、隔离服务及 UI 回归不代替这些验收，因此继续以预览版发布。Electron Desktop 原生宿主、子 agent 树和第三方计费余额不在本版 Windows 接入范围内。

## 0.2.0 — 2026-10-10

- 重做账号、设置、信息和新建页面，支持系统明暗与强调色、Pox 主题、统一菜单和确认框。
- 支持账号、客户端分组和会话拖动排序；刷新保留当前列表对象。
- 新建账号后启动客户端，目录丢失时可重新定位，移除账号可选择回收数据目录。
- 补齐会话文件菜单、单 Codex 实例深链、接力来源与目标记录；剪贴板失败不会生成重复文档。
- 桌宠面板随拖动移动，支持恢复位置、圆角标签、任务反馈与完成气泡。
- 改为进程内状态查询，减少常驻开销；增加多屏定位与损坏偏好恢复。
- 会话文件未变化时不再重复读取，后台空闲 CPU 明显下降。
- 面板打开时显示桌宠，面板会移到桌宠旁边，不再重叠。
- 原生浮球改为纯色圆球；深色模式背景更接近系统弹出面板；托盘右键菜单点外部或按 Esc 可关闭。
- 账号卡片去掉多余空白和孤立分隔线，账号名按可用宽度截断。
- 右键菜单分隔线贯通整行；深色主题使用客户端自带的浅色图标；强调色保留系统色相但降低饱和度。
- 面板打开时切换桌宠或调整大小，面板保持不动，桌宠改到旁边；只有贴近屏幕边缘、放不下时，面板才会让位。

便携版，Windows 10 19041+ x64，解压即用，无需安装 .NET。程序未签名，首次运行若出现 SmartScreen 提示，点“更多信息”→“仍要运行”。
