## 明确边界

- API 默认关闭，自动圆桌默认关闭。用户未提供/开启 Google API，本次真实计费 API 调用 **NOT_RUN**；负向授权、响应解析和 Keychain 存取已测试。
- 有宿主沙箱时，后台进程仍继承限制。受限 Codex CLI 的一次真实启动无法验证 Claude 凭据，记录为 failed；没有绕过权限、删除失败记录或改走 API。当前 Codex 桌面对话和 Claude Code 的正向路径另有真实通过记录。
- Claude 桌面应用直接作为宿主 **NOT_RUN**。Claude Code 的成功不等于桌面应用支持所有工具。
- Intel 已交叉构建和打包，实机 **NOT_RUN**。Windows 未实现。
- 不存在公开下载源或 Release；使用 Perch 随附可选包和本地更新。未推送、上传或公开发布。
