2026-10-09，本机安装包曾成功获取 Claude 的 5h / 周额度与重置时间，以及 Codex 实时额度。该结果只证明当时账号授权与服务查询可用，不保证所有账号、所有客户端版本或未来端点变化均可用。

## 需要真实界面验收的操作

1. 冷启动后首次收起、展开与右键；面板应保持打开，外部点击和 Esc 可关闭。
2. 信息／设置在同尺寸面板中切换，底栏选中变色，再点返回，滚动和展开状态保留；“数据与限制”整行可展开，展开前后列宽及底栏位置不变，滚轮／触控板可查看完整内容。
3. 桌宠开关、原生浮球／Pox 切换、显示隐藏与主题对应关系。
4. 账号旁手动额度刷新、钥匙串授权提示及持续至少一个后台同步周期。
5. 选择接力目标，确认提示词复制与源账号调出；用户在正确原对话粘贴，让 agent 写入指定路径，再点击继续。验证待办重启恢复、缺文件提示、已有文档和取消；最后在目标新聊天粘贴发送并确认接续。
6. Intel Mac 上的实际启动与上述核心路径：发行包含 x86_64，但本机运行测试在 Apple Silicon 上完成。

这些操作尚未作为本轮自动化验收完成。当前无 Developer ID 发布签名／Apple 公证，不能把本地签名验证当作 Gatekeeper 放行或公证结果。发行限制见[发布指南](releasing.md)。

两步接力新增验证：唯一文档路径、待办持久化与重启恢复、缺失／空白／乱码文件重试、符号链接拒绝、完整副本与原文保留、取消不删文档及损坏状态备份恢复。实际向源 agent 发送提示词、生成文档并在目标新聊天发送，仍需用户完成真实跨账号验收。
