# 验证与验收

自动检查与真实界面验收分别记录，不以编译成功代替交互验证。

## 1.0.0 发布检查

- 全量 `swift test`，包括偏好迁移、账号数据保护、任务状态、额度解析与账号绑定、文档复制／日志删除、通知和桌宠生命周期。
- release 配置构建；检查应用与媒体适配器均含 arm64 和 x86_64。
- 校验应用 bundle、版本、图标、资源与代码签名；ZIP 解包后再次验证，DMG 校验后分发；输出 SHA-256。
- 运行安装包的 `--diagnose` 核对本机账号和真实额度服务返回。诊断不会输出授权内容或聊天正文。
- Git 工作区、版本与发布 tag 对齐；检查链接和脚本语法，不提交运行数据、恢复备份或构建产物。

本轮本地结果：93 项测试通过；release 通用构建、ZIP 解包签名、DMG 完整性及 SHA-256 校验通过；1.0.0 已安装并启动。

## 已有证据及其范围

2026-10-09，本机安装包曾成功获取 Claude 的 5h / 周额度与重置时间，以及 Codex 实时额度。该结果只证明当时账号授权与服务查询可用，不保证所有账号、所有客户端版本或未来端点变化均可用。

本机测试覆盖手动文档副本保存、完整正文、绝对路径、同名不覆盖、原文件不变、空／乱码拒绝、权限及历史记录删除；没有自动向其他聊天发送消息。

## 需要真实界面验收的操作

1. 冷启动后首次收起、展开与右键；面板应保持打开，外部点击和 Esc 可关闭。
2. 信息／设置在同尺寸面板中切换，底栏选中变色，再点返回，滚动和展开状态保留。
3. 桌宠开关、原生浮球／Pox 切换、显示隐藏与主题对应关系。
4. 账号旁手动额度刷新、钥匙串授权提示及持续至少一个后台同步周期。
5. 选择真实 Markdown 交接文档，确认目标账号被调出；用户在目标新聊天粘贴发送并确认接续。
6. Intel Mac 上的实际启动与上述核心路径：发行包含 x86_64，但本机运行测试在 Apple Silicon 上完成。

这些操作尚未作为本轮自动化验收完成。当前无 Developer ID 发布签名／Apple 公证，不能把本地签名验证当作 Gatekeeper 放行或公证结果。发行限制见[发布指南](releasing.md)。
