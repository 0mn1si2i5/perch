# Changelog

## 1.2.0 — 2026-10-21

- 接力和拆出需求已移除：会话右键菜单不再有“接力到…”和“拆出需求到…”，待接力卡片、设置页的交接文件夹按钮和接力记录，以及交接文档写好的通知也一并去掉。对话完成、等你回应和遇到问题的通知保留。之前留在数据目录 `handoffs/` 下的交接文档和记录不删除，Perch 也不再读取。
- 删除 API 供应商和自定义客户端（包括网页入口）。升级后第一次启动时，这些账号原样移到 Perch 数据目录的 `removed-accounts.json`；钥匙串里的 API 密钥不删，信息页写明怎么手动清理。新建页的手动添加只剩 Codex 和 Claude，其他客户端用扫描添加。
- Gemini CLI 不再查询额度，也不再读取 CLI 安装目录里的 OAuth client。
- Antigravity 额度只自动查询 Gemini 应用这一个来源。Antigravity CLI 卡片只在点刷新时运行一次 `agy -p /usage`，之前每次同步额度都会在后台启动 agy。
- 本机会话列表只解析最新 60 个文件，文件没变就用缓存。超过 2 MB 的会话不再被丢掉，Gemini CLI 的 `.jsonl` 会话也能列出。Antigravity 记录里 0001-01-01 的时间显示为“时间未知”，之前显示成公元 1 年。
- Antigravity CLI 的会话数据库缺少 `-wal` 文件时，之前每 5 秒打开失败一次、列表为空，现在按只读的不可变文件打开。读取失败（例如数据库正被加锁写入）时不再缓存成空列表，下次轮询会重读。
- 面板隐藏时轮询间隔从 5 秒改为 20 秒，打开面板时立刻刷新。
- 同一 Claude 账号同时有个人和 Team 组织时，错误提示写明原因。Claude 额度记录所属账号，换登录账号后不再显示旧账号的额度。
- 本机客户端（agy、DSH Desktop 等）换了位置后，在新建页点“自动获取可用供应商”，已添加的账号会显示“更新启动位置”，点了只改启动位置，名称、顺序和数据目录不变。之前删除供应商编辑页后没有办法修改，每次启动都报“请选择可执行文件的绝对路径”。启动失败的提示现在写明这个办法；数据目录不在时提示删除后重新扫描添加。
- 外部命令统一放进独立进程组运行，超时会结束整组进程；等待移出 Swift 并发线程。重复的网络会话配置、禁止重定向的委托和 PATH 列表各合并成一份。子进程退出后最多再读 2 秒输出，agy 留下的后台进程占着输出管道时，手动刷新不再等到 35 秒超时。
- Antigravity 和 Gemini 卡片把 Gemini 4 Argon 的周额度单独显示为“Argon 周”。之前它和 Gemini 主额度池的周额度都显示成“周”，看起来像有两个周额度。
- Codex 和 Claude 对话从进行中变成已完成、等你回应或遇到问题时，发一条系统通知，点通知调出所属客户端。同一次轮询有几个对话变化时合成一条，点了打开面板。Perch 启动前已经结束的对话不通知。本机 Claude Code 历史和 `codex exec` 启动的委派运行不通知：Claude 自己会提醒 Code 会话，委派运行由发起它的 Agent 跟进。设置页“通知”里可以关掉。桌宠的完成气泡也改用这套判断。

支持 macOS 14+，包含 Apple Silicon 与 Intel。发行包使用 ad-hoc 签名，尚未经过 Apple 公证，首次打开需在“系统设置 → 隐私与安全性”中点“仍要打开”。

## 1.1.0 — 2026-10-10

- Claude 会话按账号分别读取：每个账号显示自己桌面客户端里的会话；默认 Claude 卡片另外列出本机 Claude Code 的历史，并标记 `Code`。
- 会话可以整行拖动排序（限同一账号、同一状态），顺序会保存，不改动客户端的会话文件；单击、键盘和右键照常可用。
- 修正面板首次点击和点外部关闭的行为；会话无法直接打开到具体对话时，会说明实际会发生什么。

支持 macOS 14+，包含 Apple Silicon 与 Intel。发行包使用 ad-hoc 签名，尚未经过 Apple 公证，首次打开需在“系统设置 → 隐私与安全性”中点“仍要打开”。

## 1.0.1 — 2026-10-09

- 补齐文档接力准备流程：选择目标后复制可复用提示词，在源对话发送并生成文档，再点击“继续接力”复制正文及绝对路径，最后到目标新对话粘贴发送。
- 待接力状态可在重启后恢复，支持重新复制提示词、使用已有 Markdown 和取消；缺失或无效文档可修正后重试，取消不会删除文档。
- 简化设置与信息页；信息页折叠项整行可点击，展开后保持内容宽度稳定。
- 修复桌宠按钮启用时未使用所选桌宠强调色的问题，补充 README 产品展示与接力指引。

支持 macOS 14+，包含 Apple Silicon 与 Intel。发行包仍使用 ad-hoc 签名，尚未经过 Apple 公证。接力不会自动发送消息；用户需在源对话和目标新对话分别粘贴发送。

## 1.0.0 — 2026-10-09

首个正式 GitHub 版本，支持 macOS 14+，通用二进制包含 Apple Silicon 与 Intel。

- 管理本机多个 Codex / Claude 账号，查看任务状态、最近会话，启动或调出所属客户端。
- 实时查询两个客户端的额度和重置时间；支持手动刷新、可关闭的每 5 分钟同步、缓存回退与明确错误提示。
- 固定尺寸面板和持续显示的底栏，须知／设置原地切换；改进首次点击稳定性、文字对比度与紧凑额度布局。
- 桌宠能力默认关闭；原生静态浮球保持 macOS 外观，Pox 使用配套主题，隐藏不改变所选主题。
- 统一手动 Markdown 文档接力，复制正文及绝对路径；记录默认最近 5 条，可展开、定位文档及单条删除。
- 保留原偏好迁移和账号数据，删除旧 AI 撰写、会话提取与等待流程；整理架构、文档和发布脚本。

发行包使用 ad-hoc 签名，尚未经过 Apple 公证。Claude 查询使用客户端当前端点；授权、网络或服务变化时明确报错并保留缓存。真实界面及 Intel 设备验收范围见 `docs/acceptance.md`。
